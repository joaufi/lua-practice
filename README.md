# Lua Practice

This repo contains code for learning how to program in Lua.

## Development

### Requirements

Install Lua.
Lua can be installed with [Brew](https://brew.sh/), third-party package manager for macOS.
After installing Brew, to install Lua run:

```bash
brew install lua
```

### Running Practice Scripts

To run the practice scripts:

```bash
lua practice.lua
```

Other scripts in this repo can be run by passing the name and relative path of the script to the Lua interpreter, as in this example:

```bash
lua path/to/script/example-script-name.lua
```
